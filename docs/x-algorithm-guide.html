𝕏（旧Twitter）が公開した「おすすめ」フィードの本物のプログラム（xai-org/x-algorithm・全2,024ファイル）を全部読んで、だいじなことだけを、やさしい言葉でまとめました。

さきに3行まとめ

  1. おすすめ欄は毎回ひらくたびのオーディション。AIが「この人はこの投稿に何をしそうか」を予想して点数をつけ、上位35件だけが合格します。
  2. 点数がいちばん高いのは「共有したくなる」「返事したくなる」投稿。逆に、通報・ミュートされそうな投稿は大きくマイナスされます。
  3. 点数とは別に「見せていいかチェック」があり、スパムなどの注意シール（ラベル）が付くと、点数がいくら高くてもおすすめに出ません。

だいじなポイント：審査員は「その人専用」

点数をつけるAIは、世界共通の「良い投稿ランキング」を持っていません。見る人ひとりひとりの過去の行動（何にいいねしたか、何を素通りしたか）を見て、「この人なら」の予想をします。だから同じ投稿でも、人によって点数はぜんぜん違います。

また、投稿の文章はそのまま読まれるのではなく、「意味の住所」（セマンティックID）という数字に変換されます。意味が似ている投稿は、住所も近くなる——これが後で出てくる「同じような投稿は間引かれる」しくみにつながります。

よくある誤解に注意！　「通報1回＝いいね468個ぶん消える」ではありません。点数が掛かるのは件数ではなく、AIの予想確率です。通報は元々めったに起きない（いいねの1000分の1以下）ので、予想に影響力を持たせるために数字が大きいだけ——とソースコードのコメントに明記されています。同じ理由で、アンチが束になって通報しても、その影響は主に「そのアンチと似た人たち」のおすすめにしか及びません。さらに、タイムライン外（URL直接アクセスなど）からの操作はランキングに影響しません。

🧮
たとえるなら持ち帰って友だちに見せたくなるプリント（共有）は20点、声をかけたくなる作品（返信）は5点、なんとなくの拍手（いいね）は0.5点。そして先生に苦情がいきそうな作品（通報）は−234点。拍手の数より「共有・会話・苦情ゼロ」が勝負です。

合計点のあとに、3つの補正が入る

新人ブースト

フォロワー1,000人以下・表示1,000回未満・投稿から24時間以内のオリジナル投稿を、1画面につき1件、16位相当まで引き上げ。小さいアカウントへの「チャンス枠」。

連投は減点

同じ画面に同じ人の投稿が並ぶと、2件目は0.625倍、3件目は0.44倍…と下がる（下限0.25倍）。

フォロー外は0.75倍

フォローされていない人への表示は×0.75。実はフォロー中でも、リプライとリポストは同じく0.75倍扱い。

最後に「多様性チェック（DPP）」が働き、意味がそっくりな投稿はいちばん点数が高い1件だけが画面に残ります。

だい3しょう ── かくさん

フォロワーの外へ届く条件

フォロワー以外に届くには、AIの「探しものリスト」（検索インデックス）に載る必要があります。載るための条件と時間制限が、コードにはっきり書いてありました。

投稿直後いいね0でも24時間だけ「新着リスト」に載る。ここが最初のチャンス
いいね1個本リストに登録される。ただし投稿から49時間過ぎるといいねが来ても登録されない
いいね8個コミュニティ拡散（SimClusters）の入場券。8個未満の投稿は拡散候補にならない
いいね32個「高品質バケット」に昇格して、さらに見つけてもらいやすくなる
8時間ごとコミュニティ内の勢いスコアは8時間で半分に減る。バズは瞬発力の勝負
48時間おすすめ対象から完全に外れる（投稿の賞味期限は2日）
例外：動画10秒より長い動画だけは専用リストで最長30日（優良認定なら数年）残り続ける
🍧
たとえるなら投稿はかき氷。作りたて（最初の数時間）に食べてもらえないとどんどん溶けて（8時間で半分）、2日で完全に溶けます。でも動画だけはアイスキャンディー。冷凍庫（動画専用リスト）で1か月もちます。

「誰に」広がるかは、いいねした人で決まる

𝕏は全ユーザーを約14.5万個の「クラブ」（興味のコミュニティ）に分けています。あなたの投稿にいいねした人が「料理クラブ」の人ばかりなら、投稿は料理クラブの他のメンバーにおすすめされます。ここで大事なのは、いいねの合計数より「同じクラブの中でどれだけ集中して刺さったか」が効く仕組みだということ。100個の薄いいいねより、ひとつの界隈からの30個のほうが拡散します。

リプライとリポストは「拡散」しない

検索インデックスにはオリジナル投稿と引用ポストしか載りません。リプライ・リポストはフォロワーの外に配信されない上に、フォロワー内でも0.75倍扱い。広めたい内容は、必ず自分のオリジナル投稿（または引用）として出すのが鉄則です。

だい4しょう ── やるべきこと

点が伸びる行動 10か条

ここまでの仕組みから逆算した「アルゴリズムが応援してくれる動き方」です。

✓

1. 「共有したくなる」を最優先で作る

リンクコピー共有は+20点で全行動トップ。「あとで見返したい」「あの人に送りたい」と思われる実用情報・まとめ・保存版が最強。

根拠: ShareViaCopyLinkWeight = 20.0
✓

2. 会話が生まれる投稿にする

返信は+5点（いいねの10倍）。質問で終わる、意見が分かれる、答えたくなる——読んだ人が「ひとこと言いたくなる」形に。

根拠: ReplyWeight = 5.0
✓

3. 相互フォローの仲間を大切にする

相互フォローの相手には返信予測が+15点上乗せ（実質20点）。本物の仲間との日常的な会話が、そのままスコアの土台になる。

根拠: BidirectionalFollowReplyWeightBoost = 15.0（2026年7月導入）
✓

4. もらった返信には全部返す

会話が続くほど相手の「最近の行動リスト」にあなたが登場し、AIがあなたの投稿を出しやすくなる。特に投稿直後の1時間はリプライ対応を最優先。

根拠: 行動履歴(最大1,022件)がAIの主入力
✓

5. 投稿はフォロワーが起きている時間に

勝負は最初の数時間（勢いは8時間で半減、49時間で登録打ち切り）。フォロワーがすぐ反応できる時間帯に出す。

根拠: HalfLife = 8時間 / maxTweetAge = 49時間
✓

6. まず「身内のいいね8個」を確実に

フォロワー外への拡散はいいね8個から。薄く広くより、確実に反応してくれる濃いファンを育てるのが近道。

根拠: MinFavoriteCount = 8
✓

7. 広めたい内容はオリジナル投稿で

リプライ・リポストは拡散インデックスに載らない。他人の投稿に乗りたいときは引用ポストを使う（引用は載る）。

根拠: phoenix-rankallの適格条件
✓

8. 10秒より長い動画を混ぜる

長め動画だけが持つ「30日リスト」で、テキストの15倍長く見つけてもらえる。ただしリプライに付けた動画は対象外。

根拠: videoインデックス 48h〜720h
✓

9. 連投は間隔をあけ、内容を変える

同じ画面に自分の投稿が並ぶと2件目から減点。意味がそっくりな投稿は1件に間引かれる。1テーマ1投稿、時間を空けて。

根拠: AuthorDiversityDecay = 0.5 / DPP
✓

10. 小さいうちこそ丁寧に運用する

フォロワー1,000人以下には「新人ブースト」と専用の発見ルートがある。小アカウントは不利どころか優遇枠を持っている。

根拠: ColdStartFollowerCap = 1000 / tailインデックス

だい5しょう ── やってはいけないこと

「注意シール」が貼られる行動

𝕏は問題のある投稿やアカウントに「ラベル」（注意シール）を自動で貼ります。シールの種類によって、おすすめから消えたり、アカウントごと制限されたりします。これはスコアのマイナスよりずっと重い罰です。

✕

1. 評判の悪い外部リンクを貼る

URLの評判は自動チェックされ、悪質判定ならスパムシールが付く。プロフィールへのピン留めも監視対象。アフィリエイト運用は、リンク先の信頼性が生命線。怪しい短縮URLや誘導ページは絶対に避ける。

ラベル: SPAM / SPAM_HIGH_RECALL / MALICIOUS_URL
✕

2. コピペ・定型文の量産

そっくりな文章の繰り返しは、全投稿を横断する重複検出システムが見つけてコピペスパム判定。テンプレ投稿の使い回しは危険。

ラベル: COPYPASTA_SPAM
✕

3. バズ投稿への便乗リプライ営業

注目投稿のリプ欄での宣伝・定型文リプは、スパム度97%以上で14日間の表示抑制。

ラベル: RISKY_HIGH_VIZ_REPLY（14日）
✕

4. フォロワー外へのメンション+リンク

フォローされていない相手に@メンションで低品質リンクを送りつけると、即スパム判定のルールが存在する。

ルールID 5239 / 6754
✕

5. 機械みたいな動き

フォロー→アンフォローの繰り返し、いいね連打、フォロー直後の一括アクションなどは、行動パターン専門のAI（8種類の検出器）が監視。認証チャレンジ→凍結まである。

検出器: FollowBot / LikeBot / ReplySpamBot ほか（閾値は非公開）
✕

6. 複数アカウントで自作自演

複垢の相互いいね・相互フォローは「関連アカウント」として検出され、信用スコアへの効果がゼロに。協調ボット判定なら凍結コース。

Linked Users除外 / COORDINATED_INAUTHENTIC_BOT
✕

7. エンゲージメント乞い

「いいねした人全員フォローします」「RTで拡散祭り」等は、スパム分類のなかに専用カテゴリが用意されている（エンゲージメント farming／trading／baiting）。

Grox分類: SpamEngagementFarming ほか9種
✕

8. 釣りタイトルでガッカリさせる

開いてガッカリされると「興味なし−43.2」「ミュート−58.8」を押されやすくなる。クリックの+0.4では全く割に合わない。

NotInterestedWeight = -43.2 / MuteAuthorWeight = -58.8
✕

9. AI量産文の垂れ流し

中身の薄いAI生成文には「llm_slop（AIスロップ）」判定があり、30日間のスパムシールが付く。AIは下書きに使っても、自分の言葉に直すこと。

ラベル: SpamHighRecall（30日）
✕

10. NSFW（不適切コンテンツ）を混ぜる

直近5投稿中3投稿がNSFW判定されるとアカウントごとNSFWラベル（7日）。そうなるとフォロワー外への露出はほぼゼロに。

safety-label-user-agg: 5件中3件ルール
🏫
たとえるなら点数表が「テストの成績」なら、ラベルは「生活態度の記録」。成績がどんなに良くても、問題行動の記録が付くと発表会（おすすめ）に出してもらえません。そして記録の多く（7日〜30日）は行いを改めればちゃんと消えます。

ひとつ安心材料も。フォロワー約25,000人超、または内部の信用スコアが高いアカウントは、自動シール貼りの対象から外れて人間のレビューに回される設計です。真面目に育てたアカウントほど、誤判定に強くなります。

だい6しょう ── シャドウバン

「シャドウバン」の正体は3段階

コードを読むと、「見えなくなる」には3つのレベルがあることがはっきり分かります。俗に言うシャドウバンは真ん中のレベルです。

レベル何が起きる？主な原因（ラベル）
完全非表示フォロワーのタイムラインからも消えるSPAM、PDNA、ヘイト・暴力的発言系（FOSNR_*）、法的削除
おすすめ除外
（＝シャドウバン）		フォロワーには普通に見えるが、フォロワー外のおすすめに一切出ない。検索・拡散も止まるSPAM_HIGH_RECALL、DO_NOT_AMPLIFY、NSFW系アカウントラベル、なりすまし判定、乗っ取り疑い
ぼかし表示「センシティブな内容」の膜がかかり、タップで見られるNSFW_HIGH_PRECISION、暴力・グロ画像判定

自分で確認できる公式ツールがある

𝕏は「Under the Hood」（x.com/i/under_the_hood）という透明性ツールを試験公開しています。自分のアカウントと投稿にどんなラベルが付いたか、月ごとの集計を本人だけが見られます（アカウント歴1年以上・月10投稿以上が条件）。「最近急に伸びなくなった」と感じたら、まずここを確認しましょう。

そして大事なこと：スパム系・NSFW系のラベルの多くは期限つき（7日〜30日）です。原因になった行動をやめれば、静かに回復します。
